# Contributing to axialfans

This project is primarily maintained as part of ongoing hypersonic propulsion research. While contributions are not actively solicited, high-quality pull requests are welcome if you find this tool useful.

## Reporting Issues

If you encounter bugs, please open an issue with:
- Python and NumPy versions
- Minimal code to reproduce the problem
- Error message or unexpected behavior

## Pull Requests

For significant changes:
1. Open an issue first to discuss the approach
2. Follow existing code style (PEP 8, type hints, NumPy docstrings)
3. Include tests if adding new functionality
4. Update documentation as needed

## Code of Conduct

Be respectful and constructive. This is a small research tool, not a large open-source project with complex governance.
